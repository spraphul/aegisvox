# Configuration

The runnable complete-turn examples live under `examples/`. Model settings are explicit
operator choices. There is no bundled credential file, server allocation, voice pool,
or implicit configuration that claims to reproduce the full paper.

Use `.env.example` as a list of environment variable names, not as an executable script.
For each experiment, record model revisions/checkpoint hashes, prompts, seeds, input
manifest hashes, frontend/renderer choices, evaluation stage, and failure policy.
