# Visual assets

`hero.png` and `aegisvox-demo.mp4` are unchanged exports of the author-approved AegisVox
technical demonstration (silent version). The palette is black, mint, pearl, and lilac, with orange for
lexical edits. The demonstration uses illustrative signals without an audio track, not patient speech, actual model activations, or evidence of preservation.

The Oracle wordmark is the official supplied artwork, preserved without redrawing.
Oracle branding remains subject to trademark rights; the repository's code license
does not grant trademark rights. The separate Sydney stock photograph and conference
outro are not redistributed here. No third-party hosted font or analytics are used.
