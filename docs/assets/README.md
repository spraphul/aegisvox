# Visual and narrated media

## Current film

`aegisvox-clinical-speech-public-v6.mp4` is the author-approved public edition
of the AegisVox illustrated overview, published without the Sydney stock photo.
It has 150.9 seconds of H.264 video and female synthetic narration with a quiet
original music bed. The ending uses original animated artwork and the text
“See you at ML4H 2026 / Sydney”. `film-poster.jpg` is an encoded frame from this
same film. `film.json` records the exact file hash, duration and chapter starts.

The clinic artwork is AI-generated; the narration is synthetic. All displayed
names, signal shapes and voice-signature graphics are illustrative. They are
not patient data, actual model activations or evidence of preservation. The
video is not an official conference announcement.
